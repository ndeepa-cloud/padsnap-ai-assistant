# 🏠 Padsnap AI Assistant

An AI-powered real estate marketing 
chatbot built with Python, Flask, and 
Llama 3.3 via Groq API.

## 🎯 What it does
- Generates professional property 
  listing descriptions
- Creates social media captions 
  for properties
- Writes email marketing copy
- Suggests compelling headlines

## 🛠️ Tech Stack
- Python 3
- Flask (web framework)
- Groq API (LLM inference)
- Llama 3.3 70B (language model)
- HTML/CSS/JavaScript (frontend)
- Prompt Engineering

## 🚀 How to run locally

1. Clone the repository:
git clone https://github.com/YOUR-USERNAME/padsnap-ai-assistant.git

2. Install dependencies:
pip3 install flask groq python-dotenv

3. Create .env file:
GROQ_API_KEY=your-key-here

4. Run the app:
python3 app.py

5. Open browser:
http://127.0.0.1:5000

## 💡 How it works
This app uses prompt engineering to 
specialize Llama 3.3 as a real estate 
marketing assistant. The Flask backend 
manages conversation history and connects 
to the Groq API for fast LLM inference.
